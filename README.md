UnicodeGuardian is a professional browser extension designed to help developers, security researchers, moderators, and curious users discover, inspect, and safely analyze hidden Unicode characters (BiDi controls, zero-width characters, and invisible formatting).

### Features
- **Live Text & File Scanner:** Paste or drag/drop text to instantly evaluate character composition and risk levels.
- **Format Revealer:** Replaces invisible dangerous characters with readable tags (e.g., `Hello[RLO]world`).
- **Character Library & Inspector:** A fully searchable internal database of BiDi and zero-width characters, complete with security contexts, practical examples, and risk evaluations.
- **Page Scanner:** Inject a localized scanner onto the active webpage to visually highlight and identify invisible formatting in real-time
- **Privacy First:** 100% offline. No analytics, no telemetry, no external CDNs.

### Installation (Chromium / Manifest V3)
1. Clone or download this repository.
2. Open your Chromium-based browser (Chrome, Edge, Brave, Arc, Opera) and go to the extensions page (`chrome://extensions/`)
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the folder containing those files.

### Project Structure
- `manifest.json`: Manifest V3 configuration.
- `popup.html` / `popup.css`: User interface structure and dark/light styling.
- `js/unicode-data.js`: The central database containing Unicode properties, abbreviations, and security context.
- `js/scanner.js`: Core string manipulation and risk evaluation logic.
- `js/popup.js`: UI event listeners and data binding.
- `js/content.js`: Page manipulation script for highlighting active DOM nodes.

### Future improvements
- Add support for identifying visually confusable (homoglyph) characters.
- Enhance the file scanning to explicitly parse binary strings if dropped.   

*Created for transparency, education, and text safety.*
